# 隐私说明（免费版 1.6）

Fix Clipboard 全部功能免费，无需付费、注册、授权码或关注验证。App 不读取、保存或上传剪贴板内容，不访问个人文件、照片或通讯录，没有广告追踪、使用遥测或关注状态检查。

修复只启用本机剪贴板共享偏好，并重启当前用户的共享服务。自动修复在用户主动开启后，响应网络变化或睡眠唤醒；不会持续读取剪贴板判断故障。

诊断读取本机 Wi-Fi、Bluetooth、Handoff 偏好、VPN 和进程状态。蓝牙优先读取 macOS 系统报告；报告可能包含设备信息，程序仅提取控制器开关，不展示或上传其余信息。命令输出保存在权限 600 的临时文件，读取后删除。系统报告不可用时可主动授权备用蓝牙接口，不扫描附近设备。

本机偏好保存功能开关、上次修复时间和结果，不含剪贴板内容。免费版不读写授权钥匙串、不生成安装标识、不调用支付或授权 API。旧版本留下的钥匙串记录不会影响免费功能，也不会自动删除；如需清除，可在“钥匙串访问”中找到服务名 `local.louis.fixclipboard.license` 的旧记录。

关注作者完全自愿。小红书按钮会在浏览器打开公开原帖，用户可自行关注作者；公众号二维码在本机展示，由用户自行用微信扫描。App 不知道你是否关注，不强制加私人微信、建群或联系卖家。浏览器、GitHub、微信和小红书按各自规则处理访问与关注信息。

关闭登录启动后退出 App，移除应用即可停止运行。反馈请勿公开剪贴板内容或旧授权码。
