# 隐私说明

Fix Clipboard 不读取、保存或上传剪贴板内容，没有广告、使用行为追踪或遥测。修复只修改本机共享偏好并重启当前用户共享进程。

## 微信购买与离线授权

App 显示卖家微信二维码，不接入微信支付 SDK，也不接收你的支付凭据。你主动通过微信与卖家沟通、转账并发送本机激活码。该码是随机 UUID，不是硬件序列号。卖家的本地发码账本记录订单编号、价格、机器码和已签发授权；付款和沟通信息留在微信。

App 使用公钥在本机验证授权签名，将随机安装标识和授权码保存到钥匙串。不向 Lemon Squeezy 发送微信授权码，无需联网续期。Pro 仅绑定该安装标识，不采集 Apple ID、MAC 地址或硬件 UUID。点击复制本机激活码会覆盖当前剪贴板，仅写入该码。

停用只删除本机授权记录，随机安装标识保留；不能远程撤销离线授权或自动释放订单名额。换机、退款或删除卖家账本记录请通过购买时的微信联系卖家。删除本机钥匙串标识可能需要重新签发授权。

## 诊断与其他网络连接

蓝牙优先读取 macOS 系统报告中的控制器开关。报告可能包含设备信息，不展示或上传这些信息；命令输出暂存在权限 600 的临时文件，读取后删除。报告不可用时可主动授权备用接口，不扫描附近设备。Wi-Fi、Handoff 和 VPN 状态仅在本机使用。

点击帮助、隐私或更新链接会在浏览器打开 GitHub；网站可接收常规访问数据（如 IP）。旧 Lemon Squeezy 授权代码保留用于未来兼容，但微信模式的激活、验证和停用均不调用该 API。

偏好和上次修复记录保存在本机，不包含剪贴板内容。可关闭登录启动后退出 App，并删除 App。钥匙串服务名为 `local.louis.fixclipboard.license`，如需彻底清除可通过“钥匙串访问”删除对应项。公开反馈时不要粘贴授权码、订单或支付截图。
