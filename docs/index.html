我也遇到过这个问题：手机上已经复制好了，切到 Mac，却怎么也粘贴不过来。原本几秒钟就该完成的事，变成了反复确认蓝牙、Wi-Fi 和接力有没有打开。

后来我把经历发到小红书，才发现不少人也在为同一件事烦恼。有人手机可以复制，Mac 接不到；也有人提到，问题常出现在 VPN 或网络切换之后。评论里的共鸣，让我想把解决过程做得更省事一点。

于是有了 Fix Clipboard。先把手动重置做成一个按钮，再加上本机诊断、网络变化和开盖唤醒后的自动处理。希望下次遇到时，你能少折腾几步，继续做原来的事。

它能尝试重置 Mac 端共享服务，解决不了所有原因。如果 VPN 禁止本地通信，仍然需要调整 VPN 设置。Apple 的说明也提醒了这一点。

第一次打不开？
这里需要你手动确认。

我暂时没有加入付费 Apple Developer Program。当前 App 没有 Developer ID 签名，也未经过 Apple 公证，所以 macOS 可能阻止首次打开。这类身份验证提示不等于检测到了恶意软件，但仍需你核对下载来源。

  1. 先把 App 放进 应用程序（Applications），双击尝试打开。
  2. 若提示无法验证开发者或 Apple 无法检查 App，关闭这次提示。
  3. 打开 系统设置（System Settings）→ 隐私与安全性（Privacy & Security），向下找到安全性区域。
  4. 确认拦截的是 Fix Clipboard，点击 仍要打开（Open Anyway），按提示认证，再点「打开」。

下载之前，你可能还想知道。

需要在 iPhone 或 iPad 上安装吗？

不用。Fix Clipboard 运行在 Mac 上。两台设备仍需使用同一 Apple 账户，并开启 Wi-Fi、蓝牙和接力，保持在附近。它不能在只有 iPhone 和 iPad 的场景里重置手机服务。

为什么没有 VPN，也显示绿色？

VPN 不是通用剪贴板的必要条件。绿色表示没有检测到已连接的系统 VPN；橙色提示检查 Local Network Sharing / Allow LAN。这个检查可能遗漏第三方代理或其他设备上的 VPN，不能证明所有网络条件正常。

它能保证修好吗？

不能。它重置的是 Mac 端共享服务，无法确认服务内部是否卡住，也无法排除账户、设备距离、VPN 路由等问题。建议先用免费手动修复，确认对你的场景有帮助，再考虑 Pro。

会读取我的剪贴板、上传内容吗？

不会读取、保存或上传剪贴板内容，也没有使用行为追踪。微信授权在本机离线验证，保存在钥匙串。复制本机激活码时会向剪贴板写入该码。完整隐私说明

买断包括什么？换电脑怎么办？

个人最多 3 台 Mac，长期使用 V1.x，包含 V1.x 更新。每台 Mac 单独发码。换机或删除钥匙串中的安装标识后，请联系购买时的微信；离线停用只删除本机记录，不会自动释放名额。购买前可咨询售后与退款处理。

为什么还是候选版？

当前发布为 v1.5.0-rc.4，功能和安装包经过自动化测试，但测试不能代替所有设备组合的实际验证。它尚未公证；Intel、较旧 macOS 和不同设备间的真实效果仍可能有差异。查看版本说明。
