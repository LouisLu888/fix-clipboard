Fix Clipboard 是由 LouisLu888 发布的免费开源工具，帮助处理 Universal Clipboard（通用剪贴板）与 Handoff 的部分状态异常。也可以在网络变化或 Mac 睡眠唤醒后自动执行。

开盖之后，也能自动处理

在菜单栏勾选「网络变化／睡眠唤醒后自动修复」。合盖进入睡眠后，开盖唤醒就会进入修复流程；自动选项默认关闭。

网络变化或系统唤醒 → 等待网络可用 → 稳定 3 秒 → 满足 10 秒冷却 → 重置共享服务

若合盖未进入睡眠（例如外接显示器模式），开盖不保证触发。app 需保持运行。没有每 4 小时定时任务。

安装只需几步

  1. 进入下载页，下载 Fix-Clipboard-1.4.0-universal.zip，不要选 Source code。
  2. 双击解压，将 Fix Clipboard.app 拖入「应用程序」，再打开。
  3. 若 macOS 阻止打开，先尝试打开一次，再到「系统设置 → 隐私与安全性」选择「仍要打开」。仅在确认来源可信时放行，无需关闭 Gatekeeper 或 SIP。
  4. 在屏幕顶部找到剪贴板图标，点击「立即修复」。等待几秒，在手机上重新复制后测试。

升级前先退出旧版，再替换 app 并重新打开。完整步骤见 安装与卸载说明。

先看一眼诊断

菜单中的「诊断…」显示 Wi-Fi、蓝牙、Handoff 偏好和系统 VPN 状态，并提供「立即修复」。无法可靠读取的项目会标为未知；基础状态不代表跨设备连接正常。

它能解决什么？

VPN 导致的通用剪贴板问题也能修吗？

部分网络切换后的状态异常可能通过重置恢复；若 VPN 持续阻止本地设备通信，需要调整 VPN 的本地网络例外。工具不会修改 VPN 设置，也不能保证监听到每次 VPN、DNS 或路由变化。Apple 的排查说明也提醒 VPN 可能影响连续互通。

会读取我的剪贴板吗？

不会读取、保存或上传剪贴板正文，也不发送分析数据。修复会启用系统剪贴板共享偏好并重启当前用户的 useractivityd，可能短暂影响 Handoff。

iPhone 和 iPad 之间也能修复吗？

这个 app 只运行在 Mac 上，处理 Mac 端服务。它无法重启 iPhone 或 iPad 的服务，也感知不到仅发生在手机端的网络变化。

命令完成就表示修好了吗？

不一定。工具不是端到端健康检测器，请分别测试手机到 Mac、Mac 到手机的复制粘贴。真实 VPN 切换、实际合盖及跨设备故障恢复尚未完成端到端验证；Intel 和旧版 macOS 尚未实机验证。

Universal Clipboard Fix for macOS

Fix Clipboard by LouisLu888 is a free, MIT-licensed menu bar utility for resetting the Mac-side Universal Clipboard service. Optional recovery runs after network path changes or system wake, with a 3-second debounce and 10-second cooldown. It does not read clipboard content or change VPN settings.
