# 微信购买与发码

用户扫码加卖家微信，确认名额和价格后转账。正常价 ¥49 买断，前 50 名 ¥29，以收款顺序确认。个人最多 3 台 Mac，长期使用 V1.x，含 V1.x 更新。没有自动续费。

Pro 在系统可检测到的网络路径变化和 Mac 唤醒后自动尝试重置共享服务。手动修复、诊断和登录启动永久免费。自动修复不保证所有连接故障恢复，也不能解除 VPN 的局域网限制。

## 卖家操作

1. 确认实际收款。为订单分配唯一编号（例如 WX-20260927-001），不要把微信昵称、手机号写进编号。
2. 请用户复制升级页的本机激活码（随机 UUID）。每台 Mac 提供一个。
3. 在仓库目录执行（把占位符换成真实值）：

```sh
xcrun swift scripts/manual-license.swift issue /你的私密发码目录 WX-20260927-001 用户的本机激活码 29
```

4. 把输出的完整 `FC1.…` 授权码发给用户，用户粘贴到 App 中激活。同订单第二、第三台使用同一订单编号，分别签发。重复运行同一订单和机器会返回原码。

工具不会验证支付，请先确认收款。`orders.json` 记录订单、价格与机器码，并限制每订单 3 台、优惠订单 50 份；请始终用同一份账本。满 50 份后新订单使用价格参数 `49`。App 无联网库存，付款前由卖家确认名额。

## 密钥、备份与限制

`signing-private.key` 是发码私钥，只保存在卖家的私密目录；App 仅携带 `Commerce.json` 中的公钥。私钥和账本需一起加密备份，不要提交 Git、发送给买家或放进安装包。不要重新生成并替换现有密钥，否则新版本不能验证原授权。

新部署可用 `xcrun swift scripts/manual-license.swift keygen /你的私密发码目录` 生成密钥；已配置的项目不要重复执行。

授权码离线验证，绑定随机安装标识，标识存储在钥匙串，不采集硬件序列号。卸载后保留钥匙串可继续使用；换机或删除钥匙串后需联系卖家。离线授权不能远程撤销、退款后禁用或证明旧机已停用。App 的“停用”只移除本机记录，不释放账本名额。换机由卖家核对后人工处理；不要承诺在线设备管理。

本项目仍开源，签名防止普通伪造，不是防篡改 DRM。使用者可以修改并自行编译源码。
